# 다음 작업: 사용자가 프로젝트 목적을 알려 줄 차례

> 기록: 2026-10-12

## 상황

- 두 소스 정리, 비교, 통합 노트를 마쳤다. 원문 대조 검증은 하지 않기로 했다 ([progress.md](progress.md) 참고).
- 사용자에게는 복습이 아닌 **다른 궁극적인 목표**가 있다. 편향을 막으려고 아직 알려 주지 않았다.
- 다음 세션은 사용자에게 목표를 묻고 시작한다. 목표를 추측하거나 미리 제안하지 않는다.

## 작업 중 지킬 것

- 소스 문서나 노트에서 사실 오류를 발견하면 그 자리에서 바로잡고 `progress.md`에 기록한다.

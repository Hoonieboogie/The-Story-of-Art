# 다음 작업: 웹사이트 기획과 시제품

> 기록: 2026-10-12

## 목표

곰브리치 『서양 미술사』를 도슨트 투어처럼 보여 주는 공개 웹사이트를 만든다. 확정 사항과 미정 사항은 [website/decisions.md](../website/decisions.md)에 있다.

## 지금 상태

- 사용자 인터뷰로 큰 구조를 정했다: 8개 시대 안에 18개 방, 책이 펼쳐지는 랜딩, 아이디·비밀번호 계정, 도슨트 원고 새로 쓰기.
- 랜딩 시제품 v1을 만들었다: [prototype/](../../prototype/AGENTS.md). 확정된 것은 "책이 뜬다 → 열린다 → 타임라인"이라는 흐름뿐이다. 비주얼, 말투, 방 흐름 등 나머지는 모두 다시 정한다.

## 시작 전에

1. [website/decisions.md](../website/decisions.md)의 "미정" 목록을 확인한다.
2. 사용자 아이디어를 바꾸거나 대체 안을 낼 때는 먼저 묻는다. 사용자는 템플릿 같은 안을 싫어한다.
3. 사이트 문구는 사람이 말하듯 자연스럽게 쓴다.
4. 다음 작업은 사용자와 정한다. 후보: 비주얼 레퍼런스 조사, 방 안의 흐름 설계, 도슨트 원고 톤 잡기, 서버·계정 설계.

## 사용자와 일하는 방식

- 설명은 위에서 아래로(top-down), 짧고 직관적으로 한다.
- 사용자는 Claude에게 "곰브리치의 환생이라 불리는 최고의 미술사 선생님" 수준을 기대한다.
- 큰 결정은 전문가 페르소나(Apple 출신 UX 디자이너, 테이트·메트·퐁피두 출신 큐레이터)에게 의견을 받아 비교해 제시하면 좋아한다.
- 시제품을 보여 줄 때 사용자가 확정한 범위를 정확히 기록한다. 흐름만 승인했는데 비주얼까지 승인한 것처럼 적지 않는다.

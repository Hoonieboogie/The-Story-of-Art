# 전문가 의견: UX/UI 디자이너

> 2026-10-12 · Apple에서 10년 이상 일한 시니어 UX/UI 디자이너의 관점으로 받은 의견 (AI 페르소나) · 원고: [study-notes](../study-notes/AGENTS.md)

## 결론

**"한 편의 긴 전시 + 언제든 펼치는 지도."** 시대마다 전시실 하나(세로 스크롤 스토리 한 편)를 두고, 전시실들을 언제든 꺼낼 수 있는 연표 지도로 묶는다. 처음 온 사람은 "다음 방으로" 문만 누르며 걷고(훑기), 다시 온 사람은 지도·검색·색인으로 바로 들어간다(찾기).

## 1. 관람 방식

- **로비:** "미술이란 없다, 미술가가 있을 뿐"을 첫 화면에 두고, 그 아래 5묶음(고대·중세·근세·근대·현대) 가로 연표를 놓는다. 시간이 없는 방문자용으로 18개 방을 한 문장씩 넘겨 보는 하이라이트 투어를 둔다.
- **전시실:** 맨 위에 한 줄 요약과 대표작 한 점을 화면 가득 보여 준다. 중간에 핵심 인터랙션 1–2개를 넣고, 끝의 "다음 시대로"가 다음 방의 문이 된다.
- **찾기:** 상단에 얇은 연표 바(현재 위치 표시, 누르면 지도), 작품·작가·개념 색인, 섹션별 고유 URL을 둔다.
- **실(thread):** "아는 것을 그리기", "빛"처럼 시대를 가로지르는 개념을 따라 방을 건너뛰게 한다.

## 2. 도슨트 인터랙션

1. **고정 작품 + 스크롤 주석:** 작품은 화면에 고정하고, 글이 스크롤되면 해당 부위를 확대하고 강조한다. 예: 헤지레의 머리(측면)→눈(정면)→어깨(정면)→다리(측면)→발.
2. **"만약에" 토글:** 이집트 하인을 원근법으로 그리면 팔이 가려져 "저승에서 일을 못 한다"가 뜬다.
3. **빛 스위치 / 나란히 비교:** 카라바조·렘브란트·베르메르를 같은 틀에서 전환하고, 빛의 방향을 화살표로 표시한다.
4. **오해 카드 뒤집기:** "흔한 오해"를 퀴즈 카드로 바꾼다.
5. **실 이어 보기:** 입체주의 대목에서 헤지레가 미끄러져 들어오며 "이 원칙, 어디서 봤죠?"라고 묻는다.

## 3. 20세기 이미지 공백

- 공백은 17·18장에 몰려 있다. 뭉크·칸딘스키·몬드리안·루소·클레는 퍼블릭 도메인 가능성이 높다. 막히는 쪽은 피카소·달리·마그리트·샤갈·워홀 등이다.
- 해법: 빈 액자와 미술관 링크로 **공백을 연출**한다. 원작을 베끼지 않는 **구조 다이어그램**을 쓴다(바이올린을 여러 각도로 분해하는 애니메이션). **뿌리 작품**(세잔→피카소)을 크게 보여 준다. 18장은 **타이포그래피 중심**으로 간다.

## 4. 모바일

- 모바일을 주 환경으로 본다. 작품은 화면 위 55%에 고정하고, 글 카드는 아래에서 올라온다. 하이라이트 위치로 자동 줌한다. 핀치 줌은 "크게 보기" 모드에서만 허용한다.
- 연표 바는 하단 탭 "지도"로 접는다. 이미지는 반응형으로 넣고 지연 로딩한다.

## 5. 하지 말 것

1. 스크롤 하이재킹과 과한 패럴랙스. `prefers-reduced-motion`을 존중한다. 모션은 "볼 것"을 가리킬 때만 쓴다.
2. 작품 위에 글을 덮기, 블로그 글을 그대로 옮기기. 한 화면에는 생각 하나만 둔다.
3. 찾기를 희생한 몰입. URL 없는 단일 페이지, 검색이 안 되는 구조, 대체 텍스트 없는 이미지.

## 6. 사용자에게 물을 것

원고 손질 범위, 18장(현대)의 비중, 장당 작품 수, 저작권 기준 국가, 계정·퀴즈·영어판 확장, 성공 지표, 대표 방 3개(이집트·바로크·20세기)를 먼저 만들어 검증할지.

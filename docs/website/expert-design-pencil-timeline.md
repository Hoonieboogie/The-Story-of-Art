# 전문가 의견: 연필 선 연표 ("들어가며" 양면)

> 2026-10-13 · 시니어 디자이너(애플·디즈니 20년 경력 가정) · 사용자 아이디어(구불구불한 타임라인 선, 번호 없음, 시대별 연필 선화)를 구체화

## 결론

**선 하나가 3만 년을 지나가며, 시대마다 긋는 법을 바꾼다.** 양식은 곧 그리는 방식이므로, 연표 선의 생김새가 시대를 말한다. 번호, 사진 썸네일, 체크 표시는 뺀다.

## 1. 레이아웃

- 펼친 양면 위에 SVG 하나를 겹치고, 정거장(시대) 위치를 재서 JS로 경로를 만든다. 크기가 바뀌면 다시 만든다.
- 정거장은 높낮이를 번갈아 두어 선이 지그재그로 흐른다. 선은 책등을 지나 오른쪽 면으로 이어진다.
- **번호 대신 매듭:** 시대마다 연필을 눌렀다 뗀 작은 고리. 그 시대의 장(방) 수만큼 선 위에 짧은 눈금.
- **끝은 열어 둔다:** 마지막에 흑연 점(연필 끝) 하나. "끝이 없는 이야기".
- 오른쪽 큰 안내 문구는 지우고, 손글씨 주석 하나면 충분하다.

## 2. 시대마다 바뀌는 선

| 시대 | 선의 성격 |
| --- | --- |
| 원시·고대 | 거친 목탄 떨림, 뒤쪽은 이집트식 계단 |
| 그리스·로마 | 굵기 일정한 우아한 S자(콘트라포스토) |
| 중세 | 선이 솟아 첨두아치를 그리고 내려온다 |
| 르네상스 | 떨림 없는 자로 그은 직선, 책등 쪽 소실점으로 모인다 |
| 바로크·로코코 | 큰 소용돌이 고리 하나 |
| 혁명·낭만 | 반듯한 수평선이 파도로 부서진다 |
| 눈의 혁명 | 짧은 붓질 대시, 끝은 점묘 |
| 20세기 이후 | 각진 지그재그(입체파)에서 자유로운 낙서로, 끝은 열림 |

## 3. 정거장과 선화

- 위계: 선화 > 시대 이름 > 연대 > 한 줄 설명.
- 선화 주제: 라스코 들소 / 이오니아 기둥머리 / 고딕 창과 장미창 / 원근 바닥 격자(유일하게 자로 그은 선) / 카라바조의 빛 / 메두사호의 뗏목 / 인상, 해돋이 / 어긋난 입방체와 원.
- 연필 질감: 흑연색, 한 굵기, 채움 없음. 같은 선을 살짝 어긋나게 한 번 더 겹친다. 떨림 필터는 선화에만 건다.
- 함정: 귀여운 일러스트처럼 보이면 끝이다. 빈 곳을 남긴다. 원근 격자와 입방체가 헷갈리지 않게 한다.

## 4. 모션

- 등장: 연필 끝이 선을 따라 2.4초쯤 그어 나가고, 정거장을 지날 때마다 그 선화가 스케치된다. 재방문은 1.2초로 줄이고, 클릭하면 바로 완성.
- hover: 그 시대 구간의 선이 진해지고 나머지는 물러난다. 선화는 디즈니식 **보일링**(8fps로 선이 살아 떨림)을 hover 중인 하나만.
- 장 목록 펼침은 기존 방식 유지. (제안: 장마다 작은 글리프)

## 5. 재방문 · 모바일 · 접근성 · 방 전환

- 재방문: **연필 위에 펜으로 덧그리기.** 다 읽은 시대는 선과 선화가 잉크로 덧그려지고, 읽는 중인 시대는 진행만큼만 잉크.
- 모바일: 왼쪽 축을 따라 세로로 구불구불 흐른다.
- 접근성: SVG는 장식(aria-hidden)이고 의미는 기존 목록·버튼이 맡는다. 움직임 줄이기면 완성 상태로 바로 보인다.
- 방 전환: **밑그림에서 완성작으로.** 선화가 커지며 날아가고 그 밑에서 실제 명화가 떠오른다. 나올 때는 반대.

## 6. 뺄 것과 주의

- 삭제: 썸네일, 번호, 눈금 막대, 오른쪽 큰 제목, ✓, 진행 막대.
- 점선 구간은 dashoffset으로 그리면 깨지므로 마스크로 그린다.
- 화면 전체에 떨림 필터를 걸지 않는다. 큰 선의 떨림은 좌표에 미리 넣는다.
- 글자와 선이 겹치지 않게 1024–1280px 폭에서 따로 확인한다.

## 2차 의견 (사용자 피드백 반영)

사용자 피드백: 선화 품질이 낮고 르네상스는 무엇인지 모르겠다, 선은 매끈하게 굽이 4번이면 된다, 로고·러닝헤드·안내 문구는 뺀다.

- **선:** 시대별 필치를 버리고, 늘 내려가기만 하는 매끈한 곡선 하나. 왼쪽 면 정거장은 점의 위 오른쪽, 오른쪽 면은 점의 아래 왼쪽에 둔다. 선이 계속 내려가므로 두 자리는 늘 비어 있다.
- **선화:** 손으로 아이콘을 다시 그리지 말고, 가진 명화를 밑그림으로 윤곽을 뽑아 다듬는다. 르네상스는 다 빈치 「비트루비우스적 인간」으로 바꾼다(원래 선화라 누구나 알아본다).
- **방 전환:** 선화가 실제 그림의 같은 자리에 정확히 겹친 뒤 그림이 떠오른다.
- **모션:** 보일링과 구간 강조는 뺀다. 선이 1.6초에 그려지고, 정거장에 닿으면 점이 찍히고 선화가 그려진다.

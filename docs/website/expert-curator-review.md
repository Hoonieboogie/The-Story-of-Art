# 전문가 의견: 큐레이터

> 2026-10-12 · 테이트 모던, 메트로폴리탄, 퐁피두에서 20년 이상 일한 큐레이터의 관점으로 받은 의견 (AI 페르소나) · 원고: [study-notes](../study-notes/AGENTS.md)

## 결론

**"8개 전시실 + 입구/출구"를 한 줄 동선으로 걷는 투어형 사이트.** 전시실마다 큐레이터가 이끄는 스크롤 투어 한 편을 두고, 관내도(지도)와 색인을 곁들인다. 척추는 **"앞 시대가 남긴 문제를 다음 시대가 푼다"는 릴레이**와 **"아는 것 ↔ 본 것" 저울**이다. 지금 노트는 공부용 요약이라 도슨트 원고로 쓰려면 **다시 써야** 한다.

## 1. 전시 구성 (18개 노트 → 8실)

| 전시실 | 노트 | 방의 질문 |
| --- | --- | --- |
| 입구 | 01 | 미술은 없다, 미술가가 있을 뿐 |
| 1. 효력의 미술 | 02, 03 | 왜 '못 그린' 것처럼 그렸나? → 아는 것 |
| 2. 위대한 각성 | 04, 05 | 실제로는 어떻게 보이나? → 본 것 |
| 3. 믿게 하는 그림 | 06 | 정확함보다 명확함 |
| 4. 현실의 정복과 조화 | 07, 08 | 정확하면서 조화롭게 할 수 있나? |
| 5. 완성 이후, 빛의 극장 | 09, 10 | 다 풀린 뒤에는 무엇을 하나? |
| 6. 고객이 바뀌다 | 11, 12, 13 | 전통이 끊기면 누구를 위해 그리나? |
| 7. 눈의 혁명 | 14, 15, 16 | 내 눈에 보이는 것만 믿을 수 있나? |
| 8. 실험과 개념 | 17, 18 | 보이는 것 너머를 그릴 수 있나? |
| 출구 | 01 맺음말 | 끝없는 이야기, 다시 첫 질문으로 |

- **문제 릴레이:** 방의 문마다 "앞 방이 남긴 숙제"를 건다. 노트의 "다음 시대로"를 승격시킨다.
- **앞 방 다시 부르기:** 입체주의 옆에 헤지레를, 인상주의 옆에 벨라스케스의 붓질을 다시 세운다. 이런 장면을 3–4개 심는다.
- 18실은 관람객을 지치게 한다. 8실이면 시리즈처럼 재방문하게 만들 수 있다.

## 2. 관람 방식

혼합형이되 주인은 **전시실 단위의 가이드 스크롤**이다. 도슨트의 핵심은 순서를 대신 정해 주고, 한 번에 작품 하나 앞에 세우는 것이다. 방마다 정거장 8–12개를 둔다. 스크롤하면 디테일로 줌인하고 "여기를 보세요" 원고가 따라온다. 연표는 보조로만 쓴다. 메인에 두면 사조 이름 외우기로 돌아간다. 두 작품을 겹쳐 보는 **비교 슬라이더**를 넣고, 정거장마다 고유 URL을 준다.

## 3. 도슨트 원고의 원칙

1. **보기 먼저, 설명은 나중.** "헤지레의 어깨를 보세요. 정면입니다. 그런데 얼굴은 옆을 보죠. 이 사람, 어떻게 서 있는 걸까요?"
2. **작품 하나에 아이디어 하나, 200–350자.** 앵커 작품은 길게, 보조 작품은 한두 문장으로 쓴다.
3. **미술가의 결정으로 말한다.** "그는 이걸 버리고 이걸 택했다." 일화가 원고의 엔진이다.
4. **표와 불릿 대신 말하듯 쓴다.** 비교는 화면이 하고, 오해는 반전 한 줄, 확인 질문은 출구 퀴즈 카드로 바꾼다.
5. **공부 노트의 흔적을 지운다.** (보충) 표시, 출처 링크, 장 번호 같은 메타 정보를 빼고, 사실 검증은 별도로 관리한다.

## 4. 작품 선정

- 노트당 앵커 1점 + 보조 3–5점. 방마다 8–12점, 전체 80–100점.
- **앵커 기준:** ① 방의 질문이 눈으로 보인다 ② 줌인할 디테일이 있다 ③ 앞뒤 방과 이어진다 ④ 고해상도 퍼블릭 도메인 이미지가 있다.
- 예: 네바문의 정원, 원반 던지는 사람, 아르놀피니 부부, 의심하는 도마, 인상, 해돋이.
- **20세기:** 권리부터 다시 분류한다(법률 검토 필요). 공백 작품은 미술관 링크와 묘사 원고, 관찰 미션을 붙인 "읽는 정거장"으로 만든다. 선행 작품으로 대신 세우고, 원작을 베끼지 않는 구조 도해를 쓴다.

## 5. 하지 말 것

1. 교과서를 화면에 옮기기 (사조·연도·불릿 나열)
2. 인터랙션 과잉 (3D 갤러리 걷기, 장식용 패럴랙스, 자동 재생)
3. 이미지를 작게, 출처를 대충 (작품마다 소장처·라이선스 표기)

## 6. 사용자에게 물을 것

주 관객과 말투, 텍스트 권리(원고는 독자적으로 다시 쓰기), 범위(7장 동방 미술, 건축·조각 비중), 우선 기기와 1회 관람 시간, 사이트 이름과 참여 기능, 운영과 1차 공개 범위.

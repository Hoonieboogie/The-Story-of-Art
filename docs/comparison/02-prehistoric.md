## 1. 내용 차이

### 둘 다 다룬 것

- 목적: 장식이 아니라 **주술**. 사냥할 동물을 그려 사냥의 성공을 빌었다
- 근거: 그림이 사람이 잘 가지 않는 **깊은 동굴 속**에 있다. 과시용이 아니다
- 작품: 라스코 동굴벽화, 의식용 가면, 아즈텍 비의 신 틀랄록

### 영상에만 있는 것

- 일상의 비유로 시작: 묵주, 돌탑, 수험생 엿, 해리포터의 지팡이. "바람 → 도구 → 기도"
- "예뻐야 하는 게 아니라 **효력**이 있느냐 없느냐"
- 라스코 동굴의 평면도(황소의 방, 엑시알 갤러리 등)와 재현 동굴
- 그리기 불편한 높이와 위치, 그만큼 들인 정성
- 관찰력과 입체감: 지금 그려도 어려울 만큼 생생하다
- 흑인 청동 두상 (책 도판은 나이지리아 이페 출토)

### 블로그에만 있는 것

- **"원시"는 기술이 미개하다는 뜻이 아니다.** 다른 것은 생각이다
- 집을 짓는 것과 상을 만드는 것은 똑같이 실용적이었다
- 동굴벽화가 처음 발견됐을 때 학자들이 믿지 않았다는 일화
- 원시 미술을 볼 때 기억할 네 가지 (특히 **"미술의 역사는 기술 진보가 아니라 변화하는 생각과 요구의 이야기"**)
- 빌렌도르프의 비너스, 알타미라, 카르낙 열석, 스톤헨지, 마오리·파푸아뉴기니 조각
- 고대 아메리카 전체: 토템 기둥, 알래스카 가면, 마야 제단, 그림과 문자의 관계(방울뱀 = 번개의 기호)
- 『클릭 서양미술사』 인용 보충

## 2. 해석·강조점 차이

| 주제 | 영상 | 블로그 |
| --- | --- | --- |
| 이해의 통로 | 오늘날의 **소원 도구**에 빗댐. 공감으로 들어간다 | 책의 논지. "원시" 개념을 바로잡는다 |
| 미술가의 솜씨 | 관찰력·입체감·장인정신을 크게 강조 | 정해진 방식 안에서도 기질이 드러난다고 짧게 언급 |
| 낯선 형태 | 다루지 않음 | 눈·코·입 위치만 맞으면 나머지는 자유롭게. 실물과 달라도 통일성이 있다 |
| 장의 의미 | 미술의 출발점은 주술이다 | 이후 모든 장의 열쇠 문장("생각과 요구의 이야기")이 나오는 장 |
| "원시"의 시간 | 동굴벽화와 아프리카·아즈텍 조각을 한데 묶음 | 선사시대와 고대 아메리카를 나눠 다룸 |

**정리:** 영상은 "왜 그렸나"를 공감으로 납득시키고, 블로그는 "원시"라는 말에 담긴 편견을 걷어낸다. 영상만 보면 동굴벽화의 솜씨는 남지만, 형상이 문자와 이어진다는 점과 "원시 ≠ 오래됨"이 빠진다.

## 3. 사실 오류·충돌

| 항목 | 영상 | 블로그 | 판정 |
| --- | --- | --- | --- |
| "라스코 들소 그림" | 라스코의 들소로 소개 | 알타미라·라스코를 따로 표기 | **부분 수정.** 곰브리치 책의 들소 도판은 스페인 **알타미라** 동굴 것이다. 라스코의 대표 동물은 황소와 말이다. **(보충)** |
| 청동 두상·틀랄록의 시대 | 원시미술(동굴벽화와 같은 묶음)로 소개 | 틀랄록을 고대 아메리카로 따로 다룸 | **혼동 주의.** 이페의 청동 두상은 12–14세기경, 틀랄록은 아즈텍(14–15세기) 것이다. 선사시대가 아니다. 곰브리치는 "원시"를 시간이 아니라 부족 사회의 미술이라는 뜻으로 함께 다룬다. **(보충)** |
| 동굴벽화 발견 시기 | 언급 없음 | "19세기 스페인과 프랑스 남부에서 발견" | **부분 수정.** 알타미라는 1879년 발견됐다. 라스코는 1940년 발견이다. **(보충)** |
| 스톤헨지 | 언급 없음 | B.C. 2000, 천체 관측용 달력 | **단순화.** 여러 단계에 걸쳐 B.C. 3000년경부터 1500년경까지 지었다. 해가 하지·동지에 뜨고 지는 방향에 맞춰 놓인 것은 확실하지만 "달력"이라는 용도는 가설이다. **(보충)** |
| 미술의 시작 | 언급 없음 | B.C. 25000년 무렵 (『클릭 서양미술사』 인용) | **수정.** 프랑스 쇼베 동굴벽화처럼 이보다 오래된 예가 있다(약 3만 년 이상 전). **(보충)** |
| 마야 제단의 머리 | 언급 없음 | "죽은 사람의 머리 조각" | **부분 수정.** 곰브리치 책의 도판 제목은 **죽음의 신**의 머리다. **(보충)** |

두 소스가 정면으로 어긋나는 사실은 없다. 오류는 대부분 연대와 도판 출처를 단순하게 옮긴 데서 나온다.

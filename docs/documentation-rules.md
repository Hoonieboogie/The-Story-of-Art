# 문서 작성 규칙

1. **길이:** 모든 문서는 150줄을 넘기지 않는다. 넘으면 주제별로 나눈다.
2. **한 문서 한 주제:** 한 문서에는 하나의 주제나 내용만 담는다.
3. **파일명:** 영문 소문자와 하이픈만 쓴다. 예: `gombrich-story-of-art-summary.md`
4. **링크:** 상대 경로로 걸고, 추가하거나 옮긴 뒤 실제 파일이 있는지 확인한다.
5. **룩업테이블:** `docs/`와 각 하위 디렉토리에 `AGENTS.md`를 두고 그 디렉토리의 모든 문서와 하위 디렉토리를 표로 나열한다.
6. **갱신:** 문서를 만들거나 지우거나 옮기면 해당 `AGENTS.md`도 같이 고친다.

## 소스 문서 형식 (`docs/sources/`)

- 제목, URL, 한 줄 설명, 저장일을 적는다.
- 파일·폴더명은 소스 종류를 접두어로 붙인다. 예: `youtube-...`, `naver-blog-...`
- 내용을 분석해 여러 문서로 나눈 소스는 폴더로 만든다. 폴더에는 `AGENTS.md`와 소스 정보를 담은 `overview.md`를 둔다.
- 소스에 없는 내용을 보충하면 **(보충)** 으로 표시한다.

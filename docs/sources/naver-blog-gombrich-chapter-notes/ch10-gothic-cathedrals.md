# 10장 교회의 승리: 고딕 건축과 대성당 (13세기)

> 원문: [블로그 글](https://m.blog.naver.com/joeuning/221238653125) (2018.3.27) · 책: 10장 「교회의 승리」

## 핵심

교차 아치로 기둥이 무게를 받치자 벽 대신 **큰 창**을 낼 수 있었다. 돌과 유리로 된 고딕 대성당은 '전투적인 교회'가 아니라 **물질을 초월한 별세계**를 보여 줬다.

## 고딕 건축의 원리 (12세기 후반 북부 프랑스)

- 기둥이 아치를 지탱하면 기둥 사이의 육중한 돌은 필요 없고 큰 창문을 낼 수 있다.
- 육중하고 세속적이고 단조로운 것을 모두 없앴다. 신자들은 물질 세계를 초월한 신비를 느꼈을 것이다.

| 요소 | 설명 |
| --- | --- |
| 첨형 아치 | 둥근 아치로는 천장을 높이기 어렵다. 두 개의 활 모양 늑재를 맞붙이면 높이를 마음대로 조정할 수 있다 |
| 공중 부벽 | 궁륭의 돌은 아래뿐 아니라 옆으로도 민다. 바깥에서 받치는 부벽으로 뼈대를 완성했다. 자전거 바퀴가 살로 형태를 유지하는 것과 같다 |
| 트레이서리 | 빈 벽이나 육중한 기둥 없이 가느다란 기둥과 늑재로 짜인 내부. 창문까지 엮인 선으로 덮였다 |

## 대성당의 시대 (프랑스·독일)

- 그리스 미술가는 아름다운 육체를 형상화하는 데 관심을 뒀다. 고딕 미술가에게 기교는 수단일 뿐이었고, 목적은 성경 이야기를 더 감동적이고 믿음직하게 전하는 것이었다.
- 고딕 조각가들은 옷주름 아래 신체 구조를 보여 주는 잊힌 고전 기법을 되찾았다. '무엇을'뿐 아니라 '어떻게' 표현할지에 관심을 뒀고, 그리스의 각성기처럼 다시 자연을 관찰했다.

| 성당 | 연대 | 포인트 |
| --- | --- | --- |
| 파리 노트르담 대성당 | 1163–1250 | 멀리서도 하늘의 영광 같다. 돌의 무게를 잊게 하는 신기루 같은 건물 |
| 샤르트르 대성당 | 1194 | 북쪽 현관의 성상이 살아 있는 듯 개별 특징을 지녀 누구인지 알아볼 수 있다 |
| 스트라스부르 대성당 | 1230년경 | 옷 입은 육체를 묘사하는 고대 공식을 이해하려 했다 |
| 나움부르크 대성당 (독일) | 1260년경 | 남녀 조각상에 생명감. 금방이라도 대좌에서 내려올 듯하다 |

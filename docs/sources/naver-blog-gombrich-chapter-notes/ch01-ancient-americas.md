# 1장 신비에 싸인 기원: 고대 아메리카

> 원문: [블로그 글](https://m.blog.naver.com/joeuning/221206584050) (2018.2.12) · 책: 1장 「신비에 싸인 기원」

## 핵심

고대 아메리카의 '미술'은 즐거움이나 장식이 아니라 신화, 종교, 의식의 도구였다. 그림과 문자는 매우 가까운 관계다.

## 곰브리치의 설명 (요약)

### 북미 인디언

- 신화 속 인물과 토템을 장식적으로 표현하는 정교한 체계를 발전시켰다.
- 실제 모습을 무시하고 특징 하나만 그려도 충분했다. 독수리 부리를 가진 가면은 곧 독수리다.

### 중남미 문명

- 16세기 스페인·포르투갈 정복자가 왔을 때 멕시코의 아즈텍, 페루의 잉카가 강력한 제국을 다스리고 있었다.
- 그보다 앞선 마야는 거대한 도시, 문자 체계, 정밀한 달력을 가진 결코 원시적이지 않은 문명이었다.
- 이 문명들 중 오늘날까지 남은 것은 그들의 '미술'이다. 그것은 장식이 아니었다.

### 그림과 문자

- 번개가 거대한 뱀처럼 보였기 때문에 방울뱀은 신성하고 강력한 존재였다.
- 비의 신을 뱀의 몸으로 만드는 것은 자연스럽다. 뱀은 방울뱀 그림이면서 번개의 기호, 뇌우를 부르는 기호가 됐다.
- 형상을 만드는 일은 주술과 종교뿐 아니라 문자의 최초 형태와도 이어진다.

## 작품

| 작품 | 포인트 |
| --- | --- |
| 하이다족 추장의 집 (토템 기둥) | 부족의 전설을 설명한다. 원시적 도구로 몇 년씩 깎았고 추장의 집을 표시한다 |
| 알래스카 의식용 가면 | 사람을 잡아먹는 산도깨비. 자연의 형상을 일관된 패턴으로 변형했다 |
| 마야족 돌 제단 (온두라스 코판) | 죽은 사람의 머리 조각. 인신공양 의식을 보여 준다 |
| 아즈텍 비의 신 틀랄록 | 뱀의 몸으로 만든 신. 번개의 힘을 상징한다 |

## 보충 (블로그 인용: 『클릭 서양미술사』)

- '전기 콜럼버스 시대'는 콜럼버스 이후 유럽 문명이 영향을 주기 전까지를 말한다.
- 가면과 피리 같은 의식 도구에 마술이 깃든다고 믿었다. 장인들은 이를 만들며 자연의 힘을 달래고 부족의 안전을 빌었다.
- 지역별 예: 나바호(기하학 문양 양탄자, 모래 그림), 호피(카치나 인형, 벽화), 콰키우틀(장식된 집과 카누), 아즈텍(거대 신상), 마야(계단식 피라미드), 잉카(마추픽추).

# 4장 아름다움의 세계: 그리스 건축 양식

> 원문: [블로그 글](https://m.blog.naver.com/joeuning/221215603263) (2018.2.24) · 책: 4장 「아름다움의 세계」

## 핵심

그리스 건축의 세 양식은 **기둥 머리(주두)** 로 구분한다. 도리아식은 단순하고 탄력 있게, 이오니아식은 우아하게, 코린트식은 화려하게.

## 세 양식

| 양식 | 특징 | 예 |
| --- | --- | --- |
| 도리아 | 기둥 중간이 살짝 부풀고 위로 갈수록 가늘다. 지붕 무게가 기둥을 가볍게 누르는 것처럼 탄력 있어 보인다 | 파르테논 신전 (익티노스, B.C. 450) |
| 이오니아 | 주두 양옆이 나선형으로 장식되고, 이 장식이 대들보를 받치는 듯하다. 정교한 세부로 우아하고 아늑하다 | 에렉테움 (B.C. 420–405) |
| 코린트 | 이오니아식 소용돌이에 잎사귀 모양을 더했다. 건물 전체가 화려하다. 남은 건물은 거의 없다 | 후기 유적 |

# 28장 끝이 없는 이야기: 20세기 후반의 사조

> 원문: [블로그 글](https://m.blog.naver.com/joeuning/221315360268) (2018.7.9) · 책: 28장 「끝이 없는 이야기」

## 핵심

유행의 변화는 끝없이 이어진다. 사건은 충분한 거리를 두어야 이야기가 된다. 20세기 후반 미술은 **어린아이 같은 자발성**과 **순수 회화에 대한 고답적 관심**이라는 두 기준 사이에서 다다, 액션페인팅, 앵포르멜, 옵아트, 팝아트로 갈라졌고, 일부는 다시 **구상**으로 돌아왔다.

## 사조와 미술가

| 사조 | 설명 | 미술가와 작품 |
| --- | --- | --- |
| 다다 | 1차 세계대전 중 취리히에서 시작. '다다'는 아이의 장난감 같은 유치한 음절. 아이가 되어 예술의 진지하고 과장된 태도를 경멸하려 했다. 미술품과 다른 인공물의 차이가 흐려졌다 | 쿠르트 슈비터스 「보이지 않는 잉크」 (1947): 버스표, 신문 조각, 누더기를 붙였다 / 마르셀 뒤샹 「샘」 (1917): 일상 사물(레디메이드)에 서명했다 |
| 액션페인팅 | 아이의 낙서 같은 자발성 + 순수 회화의 고답적 문제. 미리 계획하지 않고 자발적으로 분출해야 한다 | 잭슨 폴록 「작품 No.31」 (1950): 캔버스를 바닥에 놓고 물감을 떨어뜨리고 붓고 뿌렸다 / 프란츠 클라인 「하얀 형태들」 (1955): 선이 바꿔 놓은 여백에도 주목하라 |
| 타시즘 (프랑스) | 동기와 상관없이 붓질이 남기는 흔적(tache, 얼룩) 자체에 관심 | 피에르 술라주 「1954년 4월 3일」: 힘찬 붓질의 농담으로 3차원의 인상 |
| 앵포르멜 | 물감의 질감(텍스처)에 몰두. 진흙, 톱밥, 모래, 마대, 플라스틱, 녹슨 쇠까지. 회화와 조각의 중간 | 졸탄 케메니 「파동」: 금속으로 만든 추상. 18세기 풍경화가 자연에서 '그림 같은' 아름다움을 찾게 했듯, 도시의 물질에서 경이를 찾게 한다 |
| 옵아트 | 형태와 색이 상호작용해 의도하지 않은 번뜩임과 현란함을 만드는 시각 효과 | 브리짓 라일리 「사각형 속의 움직임」 (1961) |
| 팝아트 | 대중을 열광시킨 팝 음악처럼, 누구나 아는 만화와 광고를 쓸 수 없을까? | 리처드 해밀턴 「오늘날 가정을 색다르고 멋지게 만드는 것은 무엇인가」 (1956) |
| 추상에서 구상으로 | 실험만 있는 게 아니다. 주목받은 작가 중 일부는 구상으로 돌아왔다 | 니콜라 드 스탈 「아그리젠토 풍경」 (1953) / 마리노 마리니 「말 탄 사람」 (1947): 공습 때 말을 타고 도망치는 농부, 영웅적 기마상과 대조되는 비애 / 조르조 모란디 「정물」 (1960): 같은 병과 단지를 수없이 그려 존경을 얻었다 |

- 블로그는 케메니 「파동」의 연도를 '1595년'으로 적었는데, 케메니(1907–65)의 생애로 보아 오기다. 정확한 연도는 확인하지 못했다. **(보충)**

# 임토끼 블로그: 곰브리치서양미술사 카테고리 (개요)

- **URL:** https://m.blog.naver.com/joeuning?categoryNo=94&tab=1
- **종류:** 네이버 블로그 (글 22편, 2018.2–2018.7)
- **설명:** 『서양 미술사』(예경, 2003)를 서문부터 28장까지 장별로 정리한 글 모음.
- **저장일:** 2026-10-12

## 한 줄 요약

책의 각 장을 시대와 지역별로 나눠, 곰브리치의 설명과 대표 작품을 정리했다.

## 문서화 방식

- 블로그 본문은 책 한국어판 문장을 그대로 옮겨 적은 발췌가 대부분이다. 그래서 원문을 복사하지 않고 **요약**했다. 원문은 각 문서 맨 위의 링크로 확인한다.
- 블로그가 함께 인용한 다른 책(『클릭 서양미술사』, 『세계문화사』, 『서양 복식사』)의 내용은 "보충 (블로그 인용)"으로 구분했다.
- 블로그의 사실 오류는 **(보충)** 으로 바로잡았다.
- 한 블로그 글이 여러 장이나 지역을 다루면 문서를 나눴다.
- 7장(동방의 미술)을 다룬 글은 없다.

# 미술사를 보는 관점과 사조 지도

> 영상 [0:00–1:28](https://www.youtube.com/watch?v=Pq4eS54GPAE&t=0s), 맺음말 [68:50–69:46](https://www.youtube.com/watch?v=Pq4eS54GPAE&t=4130s)

## 핵심

"미술이 아니라 미술가가 존재한다." 작품보다 **미술가와 그가 살았던 시대**에 집중하면 감상이 훨씬 즐거워진다.

## 곰브리치의 관점

- 책 첫머리의 문구: 미술(Art)이라는 것은 없고, 미술가들이 있을 뿐이다.
- 미술 자체보다 미술가, 그리고 미술가가 살았던 시대에 집중한다.

## 사조 지도

영상 판서([6:25](https://www.youtube.com/watch?v=Pq4eS54GPAE&t=385s))에 나온 전체 흐름이다.

1. 원시미술 → 이집트 → 그리스 → 로마 → 중세
2. 르네상스 → 바로크·로코코 → 신고전주의 → 낭만주의 → 사실주의
3. 인상주의 → 후기인상주의 → 표현주의 → 입체주의 → 다다이즘 → (추상, 팝아트)

- 이집트·그리스·로마 미술은 르네상스에 영향을 줬고, 르네상스는 지금의 아카데믹한 미술까지 이어진다. 그래서 이 셋이 서양 미술의 근간이다.
- 19세기까지는 한 시기에 한 사조라 순서대로 나열하기 쉽다. 20세기부터는 사조가 동시에 여러 개 생겨 복잡해진다.

## 맺음말

- 미술이 사랑받아 온 이유: 보이는 것부터 보이지 않는 것까지 표현하려는 미술가들의 노력이 미술의 역사를 만들었다.
- 그 역사는 우리에게 재미있는 옛날 이야기가 된다.
- 서양 미술이 어렵게 느껴지면 그림보다 **이야기**에 집중해서 보자.

    1. 「네바문의 정원」, 기원전 1400년경. 영국박물관. 퍼블릭 도메인
    2. 조토, 「그리스도를 애도함」, 1305년경. 파도바 스크로베니 예배당. 퍼블릭 도메인
    3. 얀 반 에이크, 「아르놀피니 부부의 초상」, 1434년. 런던 내셔널 갤러리. 퍼블릭 도메인
    4. 카라바조, 「의심하는 도마」, 1602–03년. 포츠담 상수시 궁전. 퍼블릭 도메인
    5. 요하네스 베르메르, 「물주전자를 든 젊은 여인」, 1662년경. 메트로폴리탄 미술관 오픈 액세스. 퍼블릭 도메인
    6. 자크루이 다비드, 「호라티우스 형제의 맹세」, 1784년. 루브르 박물관. 퍼블릭 도메인

    8. 바실리 칸딘스키, 「구성 VII」, 1913년. 트레티야코프 미술관. 퍼블릭 도메인

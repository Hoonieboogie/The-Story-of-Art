      도판 출처

      도판 출처

      1. 「네바문의 정원」, 기원전 1400년경. 영국박물관. 퍼블릭 도메인
      2. 미론, 「원반 던지는 사람」 로마 시대 복제본. 로마 국립박물관 팔라초 마시모. 사진 Livioandronico2013, CC BY-SA 4.0
      3. 조토, 「그리스도를 애도함」, 1305년경. 파도바 스크로베니 예배당. 퍼블릭 도메인
      4. 얀 반 에이크, 「아르놀피니 부부의 초상」, 1434년. 런던 내셔널 갤러리. 퍼블릭 도메인
      5. 카라바조, 「의심하는 도마」, 1602–03년. 포츠담 상수시 궁전. 퍼블릭 도메인
      6. 요하네스 베르메르, 「물주전자를 든 젊은 여인」, 1662년경. 메트로폴리탄 미술관 오픈 액세스. 퍼블릭 도메인
      7. 자크루이 다비드, 「호라티우스 형제의 맹세」, 1784년. 루브르 박물관. 퍼블릭 도메인
      8. 클로드 모네, 「인상, 해돋이」, 1872년. 마르모탕 모네 미술관. 퍼블릭 도메인
      9. 바실리 칸딘스키, 「구성 VII」, 1913년. 트레티야코프 미술관. 퍼블릭 도메인

      베르메르는 메트로폴리탄 미술관, 나머지는 위키미디어 커먼즈에서 가져왔어요.

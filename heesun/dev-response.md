# 개발 담당자의 답변

개발 담당자가 heesun의 질문(`to-dev.md`)에 답할 때 여기에 적는다. 위에 새 행을 추가한다.
heesun 세션이 시작되면 AI가 "새 답변"을 찾아 heesun에게 쉬운 말로 전하고, 상태를 "전달 완료"로 바꾼다.

- 칸은 `ID | 질문 | 답변 | 상태` 순서. 답변 안에 `|` 기호는 쓰지 않는다.
- 답변은 heesun이 그대로 읽어도 되게 개발 용어 없이 쓴다.
- 상태: 개발 담당자는 "새 답변"으로 적고, heesun 세션이 전달하면 "전달 완료"로 바꾼다.

| ID | 질문 | 답변 | 상태 |
| --- | --- | --- | --- |
| 2026-10-22-1 | 웹사이트 시안의 연표(연필 선 하나로 내려가는 8개 시대)를 왜 이런 방식으로 만들었나요? 칸 나눔 연표와 어떻게 섞을 수 있을까요? | 만든 이유는 두 가지예요. 하나는 서양미술사를 큰 흐름부터 세부 내용까지 계속 이어서 잘 이해하려는 것이고, 다른 하나는 다른 사람들도 쉽고 재미있게, 직접 참여하면서 배울 수 있게 하려는 것이에요. 두 방식을 섞는 안은 아직 정하지 않았고, 개발 담당자가 시안을 보고 따로 제안할 예정이에요. | 새 답변 |
